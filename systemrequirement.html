🖥️ System Requirement for all Packages

Requirements for Training on Android Application Development

📱 Android Studio (Virtual Device)

  • BlueStacks: 6GB+ RAM, 1GB+ shared memory, 2.0+ GHz CPU
  • Other Virtual Device: Must support virtualization (also for Flutter & Java)

🔌 Android Studio (Physical Device)

  • 4GB RAM, 1GB+ shared memory, 1.6+ GHz CPU
  • Attach external Android device for testing
  • Also for Flutter & Java

💻 Flutter in VSCode

  • 4GB RAM, 1GB+ shared memory, 1.6+ GHz CPU
Requirements for Training on Web Application Development

🌐 Raw Code

  • 500MB or 1GB+ RAM
  • 1+ GHz processor

🛠️ IDE & Raw Code

  • 2GB RAM
  • 1+ GHz processor
Requirements for Training on Video Editing

🎬 Adobe Premiere

  • 4GB RAM
  • 1GB dedicated video memory (not shared)
  • 1.6+ GHz CPU
  • Processor: Core i5 or related
  • Storage: 100GB free space
  • Screen: 14.6"+, 1000x600+, Windows 8+
  • Optional: Side-ways cooling holes (e.g. Dell precision m4500, core i7)

🎥 Camtasia

  • 4GB RAM
  • 1GB+ shared memory
  • 1.6+ GHz CPU
  • Processor: Pentium R, Dual core, core 2 duo, core i3+ or related
  • Storage: 100GB free space
  • Screen: 14.6"+
Screen resolution: 1000+ width, 600+ height, Windows 8 and above.
Optional: Side-ways cooling holes. Example: HP ProBook 4330s

💡 Focusky or Crazy Talk

  • Pentium M, R and above
  • 2GB RAM
  • 1+ GHz processor

🚀 Full/Advanced Video Editing

  • 8GB+ RAM
  • 2GB+ dedicated Nvidia graphics (not shared)
  • 2.0+ GHz multi-core CPU
  • Processor: Core i7 or Ryzen 5/7 recommended
  • Storage: 250GB+ free SSD space
  • Screen: 15.6"+, Full HD (1920x1080+), Windows 10/11 or MacOS
  • Optional: External cooling pad for heavy rendering
